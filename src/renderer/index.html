Priorität: Wird die CPU knapp, bekommt das Spiel zuerst Rechenzeit, Gedrosselte zuletzt.

Kerne: Gedrosselte laufen nur auf den hinteren Kernen – der Rest bleibt frei fürs Spiel.

Grafikkarte: Spiele auf die starke GPU, Gedrosselte auf die Stromspar-GPU (bei Laptops mit zwei GPUs). Gilt ab dem nächsten Start des Programms.

Upload-Limit: Bremst, was ein Programm hochlädt, damit der Ping stabil bleibt. Downloads lassen sich unter Windows ohne Treiber nicht bremsen.

Beim Beenden setzt Vorrang alles auf die ursprünglichen Werte zurück.
